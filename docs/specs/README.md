# Spécifications par module

Une fiche par module métier. Chaque fiche contient :
- Les règles de gestion retenues (extraites de `../../analyse.md`).
- Les cas particuliers validés par le métier.
- Le modèle de données associé.
- Les règles d'acceptation (tests).

Convention de nommage : `NN-nom-du-module.md` (ex. `01-patrimoine.md`).
