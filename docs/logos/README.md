# Logos — Syndic Alpha

Marque : un toit posé sur les lignes d'un registre (copropriété + comptabilité).
Source de vérité : `apps/web/src/components/wordmark.tsx` (`LogoMark`).

| Fichier | Usage |
|---|---|
| `syndic-alpha-logo-light.png` | Logo complet (marque + « Syndic *Alpha* »), fond transparent, pour fonds **clairs** |
| `syndic-alpha-logo-dark.png` | Idem pour fonds **sombres** |
| `syndic-alpha-logo-{light,dark}-bg.png` | Logo complet sur le fond de l'application (os clair / encre sombre) |
| `syndic-alpha-mark-{light,dark}.{svg,png}` | Marque seule, transparente (1024 px) — base des favicons |
| `syndic-alpha-icon-{light,dark}.{svg,png}` | Tuile d'application (carré arrondi plein) — icône PWA / Apple |

Couleurs : vert forêt `#194838` (clair) · vert sauge `#69b591` (sombre) ·
encre `#1d1a16` / os `#eae7e1` · os `#f7f6f2` / encre `#131210` (fonds).
Typo du logotype : Fraunces (500, « Alpha » en italique).

Favicons dérivés : `apps/web/public/icons/` (+ `apps/web/public/favicon.ico`).
